## Primary Colors

| Name | Hex | RGB | Usage |
|------|-----|-----|-------|
| **Accent (Amber)** | `#b45309` | rgb(180, 83, 9) | Primary buttons, links, icons, section headers |
| **Success (Emerald)** | `#10b981` | rgb(16, 185, 129) | Online status badges, active indicators |
| **Success Dark** | `#16a34a` | rgb(22, 163, 74) | Hover states for success elements |

## Gradients

### Page Background (Light Mode)
```css
background: linear-gradient(180deg, #fafafa 0%, #f8f8f8 45%, #f4f4f5 100%);
```

### Card Background
```css
background: linear-gradient(180deg, #f8f8f8 0%, #fafafa 100%);
```

### Project Card Overlay
```css
background: linear-gradient(0deg, #000000 0%, #000000 10%, transparent 90%, #000000 100%);
```
